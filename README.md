Current Lab: Network Troubleshooting Assistant
Status: Early prototype
File: Network-Troubleshooting-Assistant.pkt
Purpose:
This lab is the beginning of a troubleshooting-focused Packet Tracer enviroment
designed to help me practice identifying and resolving common network issues.

What this lab will eventually teach:
- Basic IP addressing and connectivity checks 
- VLAN identification and misconfiguration detection
- Routing verification (static or dynamic, depending on future expansixons)
- ACL behavior and traffic filtering
- Switchport and interface troubleshooting
- Device-to-device communication flow analysis

Current State:
  This lab is currently a bare-bones starting point. I have not yet built out the 
  full topology, added misconfigurations, or run formal tests. it exists as the 
  foundation for a more complete troubleshooting enviroment.

Tools Used:
  - Cisco Packet Tracer (CPT)
  - Windows 10/11
  - GitHub for documentation and version control
 
Learning Objectives:
  As explained this repo, my goals are to:
  - Build hands-on networking troubleshooting experience
  - Strengthen my understanding of Cisco IOS comands
  - Document problems and solutions clearly for future reference
  - Create a profile of practical labs aligned with Cybersecurity work
  - Develop repeatable troubleshooting workflows
